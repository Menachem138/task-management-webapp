## Current Bot Implementation (bot.py)
1. Command-based Features:
   - Requires /search command
   - Basic keyword matching
   - Accent normalization implemented
   - Audio file delivery via /audio command
   - Synonym support via SYNONYMS dictionary

2. Search Algorithm:
```python
def calculate_search_score(text: str, keywords: List[str]) -> Tuple[int, List[str]]:
    normalized_text = normalize_string(text)
    matches = []
    score = 0
    for keyword in keywords:
        variations = get_word_variations(keyword)
        for variation in variations:
            if normalize_string(variation) in normalized_text:
                score += 1
                matches.append(variation)
    return score, matches
```
